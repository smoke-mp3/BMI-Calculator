BMI-Calculator
A simple command-line application to calculate Body Mass Index.

![Python Version](https://img.shields.io/badge/python-3.8-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

BMI-Calculator is a straightforward Python script designed to help users quickly calculate their Body Mass Index (BMI). 

*   Calculates BMI based on user-provided weight and height.
*   Interprets BMI results into standard categories (Underweight, Normal, Overweight, Obese).
